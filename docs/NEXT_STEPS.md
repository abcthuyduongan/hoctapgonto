# BƯỚC TIẾP THEO SAU ALPHA 2

1. Trên máy Windows có Internet, cài thư viện, sửa mọi lỗi xuất hiện khi `npm run typecheck` và `npm run build`. Chạy E2E browser cho các luồng 3 game, 2 mẫu Creator và báo cáo.
2. Phát hiện và xử lý lỗi P0/P1 trong multi-tab IndexedDB và vòng đời React StrictMode (reload/abandon/complete).
3. Thêm chức năng xuất/nhập bản sao lưu local **có xác nhận**, trước khi dùng dữ liệu cần giữ lâu.
4. Xây dựng `learner profile`, `content library` và `assignment` theo nhu cầu thật, không chỉ bổ sung màn hình.
5. Thiết kế auth/bảo mật phụ huynh và RLS backend trước khi đồng bộ dữ liệu trẻ em.
6. Mở rộng Creator Studio sang trắc nghiệm Math Quest, thư viện game templates, âm thanh/hình ảnh; thử nghiệm độc lập trước khi gắn vào hệ thống chính.
