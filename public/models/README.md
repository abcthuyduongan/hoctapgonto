# Mô hình đang dùng

Năm mô hình chính: fox-guide.glb, math-world.glb, memory-world.glb, language-world.glb, environment.glb. Nguồn, quyền sử dụng và hash trong docs/ASSET_LICENSES_V37.md; tạo lại bằng npm run assets:build.

fox-guide-prototype.glb và fox-guide-mobile.glb vẫn được renderer dự phòng dùng khi WebGL/Three không sẵn sàng. Chúng là tài nguyên đồ họa đang được dùng, không phải một giao diện ứng dụng cũ.
